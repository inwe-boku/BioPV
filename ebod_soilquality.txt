Download maps over vector tile server with python script
read all Tileson.py
script is optimised for this server and for the zoom level 14, it could be that other zoom level or other vector tile server don't work with the script provided; the applicable zoom factor is from TileJSON file as are the bounderies witch were converted to tile coordinates with coordinates.py

working in QGIS
reproject to EPSG 31287
delete all polygons without data (non agricultural areas)
create new column bofo_id_new as integers
dissolve to dissolve overlaping polygons by the column bofo_id_new
multipart to singelpart to split up multipolygons
fix geometry
